여기부터

앱 실행 → 자료 연결 → 리포트 읽기

이 앱은 리포트를 모아 읽는 곳이에요. 처음에 목록이 비어 있어도 정상이에요. GitHub에서 받거나 Outlook·파일로 가져오면 채워져요.

먼저 앱을 열어요

처음 설치할 때는 배포받은 AVReportHub-Setup.exe를 실행해요. 설치가 끝나면 브라우저에 리포트 화면이 열려요. 다음부터는 바탕화면의 AV Report Hub를 실행하세요.

GitHub 자료를 연동할까요?가 나오면 게시된 리포트를 받을 때는 연동하기, 회사에서 GitHub를 사용할 수 없거나 메일·파일로 시작할 때는 연동하지 않기를 눌러요. 나중에 설정에서 바꿀 수 있어요.

이 앱의 GitHub 연결 상태리포트 화면 상단의 상태 표시를 누르면 확인할 수 있어요.

GitHub가 연결되어 있어요 ↓게시된 리포트를 받아 바로 읽어요. GitHub 없이 사용할래요 ↓Outlook 메일함이나 PST 파일을 연결해요.

GitHub는 담당자가 올린 리포트를 받아오는 온라인 보관소예요. GitHub 연결 없이도 Outlook·MD·PDF·노트를 사용할 수 있어요. 기본 기능에는 Git·Python·Node.js 설치가 필요하지 않아요.

GitHub가 연결되어 있을 때

  1. 리포트 화면 상단의 상태 표시를 눌러 최신 자료 확인 완료인지 확인해요. 확인 중이면 잠시 기다려요.
  2. 왼쪽 데일리리포트를 누르고, 목록에서 읽을 제목을 눌러요. 본문이 옆에 열려요.
  3. 새 자료를 바로 확인하려면 상단 지금 업데이트를 눌러요. 앱을 실행할 때와 설정한 시간에도 자동으로 확인해요.

완료 확인: 데일리리포트 목록에 제목이 보이고, 누르면 본문을 읽을 수 있어요. 목록이 비어 있으면 검색어와 검색 조건을 초기화해 보세요.

GitHub를 새로 연결하거나 다시 연결하려면
  1. 왼쪽 설정 → 자료 연결 · 자동 업데이트를 열어요.
  2. GitHub 자료 연동을 켜요. 기본 배포 자료를 사용할 때는 입력되어 있는 소유자·저장소·브랜치를 그대로 두세요. 별도 저장소를 안내받았다면 담당자가 준 값을 넣어요.
  3. 공개 저장소는 접근 토큰을 비워 두어요. 비공개 저장소라면 담당자에게 접속 정보와 읽기 권한을 확인해요.
  4. 검사하고 저장을 누르고 결과를 확인해요. 연결에 성공하면 데일리리포트에서 읽을 수 있어요.

연결에 실패하면 연동이 자동으로 꺼질 수 있어요. 회사에서 GitHub에 접속할 수 없다면 아래 Outlook 방법으로 시작하세요.

GitHub가 연결되어 있지 않을 때

메일로 받은 리포트를 가져오면 돼요. 클래식 Outlook이 설치되어 있고, 사용할 메일함이 설정되어 있어야 해요. 먼저 Outlook을 열어 메일을 볼 수 있는지 확인하세요. 새 Outlook은 이 앱의 연동을 지원하지 않아요.

평소 Outlook에서 읽는 메일은 아래 메일함 연결을 따라 하세요. 별도로 받은 .pst 파일이 있다면 PST 파일 연결 순서로 이동하세요. 두 가지를 모두 할 필요는 없어요.

이미 쓰고 있는 Outlook 메일함 연결
  1. AV 리포트 화면으로 돌아와 왼쪽 Outlook을 눌러요.
  2. 메일함에서 리포트 가져오기를 펼치고 Outlook 메일함 불러오기를 눌러요.
  3. 원하는 메일함 옆의 폴더 선택을 눌러요.
  4. 리포트 메일이 들어 있는 폴더를 찾아 이 폴더 추가를 눌러요. 예를 들어 ‘데일리 리포트’ 폴더에 메일을 모았다면 그 폴더를 선택해요.
  5. 자동 가져오기가 시작돼요. 아래 Outlook에서 가져온 리포트에 제목이 나타나면 눌러 읽어요. 데일리리포트에서도 볼 수 있어요.

하위 폴더는 각각 추가해야 해요. 새 메일을 바로 확인하려면 Outlook 탭의 지금 가져오기를 눌러요. 앱이 실행 중이면 5분마다 자동으로 확인해요.

PST 파일로 Outlook 연결하기

PST(.pst)는 Outlook 메일을 담아 둔 보관 파일이에요. 리포트 메일이 들어 있는 PST 파일을 이 PC에 준비하세요. 파일이 없다면 담당자에게 보관 파일을 받거나 위의 메일함 연결 방법을 이용하세요.

  1. 클래식 Outlook을 열어 사용할 수 있는지 확인해요. PST 연결에도 클래식 Outlook이 필요해요.
  2. AV 리포트 → Outlook → 메일함에서 리포트 가져오기를 펼쳐요.
  3. 경로 추가를 누르면 파일 선택 창이 열려요. 준비한 .pst 파일을 고르고 열기를 눌러요.파일 위치를 알고 있다면 전체 경로를 입력하고 ‘입력 경로 추가’를 눌러도 돼요. 예: C:\Reports\DailyReport.pst
  4. 연결된 메일함·폴더 목록에 추가된 파일을 찾아 옆의 폴더 선택을 눌러요.
  5. 리포트 메일이 들어 있는 폴더 옆의 이 폴더 추가를 눌러요. 하위 폴더도 필요하면 따로 추가해요.
  6. 가져오기가 끝나면 Outlook에서 가져온 리포트에 제목이 나타나요. 제목을 눌러 읽거나 데일리리포트로 이동해 확인하세요.

파일만 추가하면 아직 리포트를 가져오지 않아요. 반드시 폴더 선택 → 이 폴더 추가까지 진행하세요. 연결 후에는 파일을 같은 위치에 두세요. 메일이 많으면 첫 가져오기에 몇 분 이상 걸릴 수 있어요.

OST 파일만 있거나, 파일을 연결할 수 없어요

OST(.ost)는 현재 Outlook에 설정된 메일함의 저장 파일이에요. 다른 PC에서 복사해 온 OST 파일만으로는 연결할 수 없어요. 현재 Outlook의 메일함을 불러오거나, 담당자에게 PST 파일을 요청하세요.

PST가 열리지 않으면 파일 위치와 접근 권한을 확인하고 클래식 Outlook에서 해당 파일을 열 수 있는지 확인해요. 회사 정책으로 Outlook 연결이 제한되면 사내 IT 담당자에게 문의하세요.

Outlook 없이 파일로 시작하려면

  • MD 리포트(.md)를 받았다면 상단 가져오기에서 선택해요. 정해진 리포트 양식의 파일만 데일리리포트에 들어가요.
  • PDF(.pdf)는 내 자료 → PDF 추가로 넣고, 내 자료 목록에서 읽어요.
  • 일반 Markdown 문서는 노트 → MD 가져오기로 열어요. Markdown은 글을 담는 .md 형식의 문서예요.

연결했는데 리포트가 안 보이나요?

Outlook에 ‘연결 폴더 0개’라고 나와요.
메일함이나 파일만 추가한 상태예요. 폴더 선택 → 이 폴더 추가까지 진행하세요.
메일은 많은데 가져온 리포트가 없어요.
일반 메일은 리포트 목록에 들어가지 않아요. 리포트 양식의 본문이나 .md 첨부가 있는지 확인해요. 전달된 원본 메일(.msg) 안의 MD도 읽을 수 있어요. ‘MD 형식 확인 필요’가 나오면 발신자에게 리포트 양식을 확인하세요.
새 메일을 받았는데 목록이 그대로예요.
Outlook → 지금 가져오기를 누르고 진행 안내를 확인해요. 상단의 지금 업데이트는 GitHub 자료를 확인하는 버튼이에요.
가져오기는 끝났는데 데일리리포트에서 안 보여요.
초기화로 검색 조건을 지워요. 숨긴 리포트는 설정 → 삭제한 리포트 복원에서 꺼낼 수 있어요. 같은 날짜·같은 본문은 목록에 한 번만 표시돼요.

첫 리포트를 읽었다면 준비 완료예요. 다음부터는 앱을 열고 데일리리포트 → 제목을 누르면 돼요. 찾는 글이 많으면 검색칸에 회사 이름이나 궁금한 단어를 입력하세요.

데일리리포트

궁금한 소식을 찾아 읽는 곳이에요.

  1. 위쪽 검색칸에 회사 이름이나 궁금한 말을 써요.예: 현대차
  2. 목록에서 제목을 누르면 글이 열려요.
  3. 너무 많이 나오면 검색 조건에서 회사나 날짜를 골라요.

검색어와 검색 조건을 지우려면 초기화를 눌러요.

내 리포트도 함께 보기

가져오기로 정해진 양식의 MD 리포트 파일을 넣을 수 있어요. Outlook에서 가져온 리포트도 여기에 모여요. 같은 내용은 한 번만 보여요.

목록의 삭제는 글을 숨기는 기능이에요. 다시 보고 싶으면 설정 → 삭제한 리포트 복원을 이용해요.

처음에는 리포트 목록이 비어 있을 수 있어요. GitHub를 연동하거나 Outlook·MD 자료를 가져오면 표시돼요. GitHub를 꺼도 Outlook 리포트는 데일리에 표시돼요.

지금 업데이트는 GitHub 자료를 확인하는 버튼이에요. Outlook 메일은 Outlook 탭의 지금 가져오기로 확인해요. GitHub 자료는 연동을 켜고 연결에 성공했을 때만 표시·다운로드할 수 있어요.

가져온 리포트는 MD 다운로드를 이용해요. PPTX 다운로드는 해당 첨부가 있는 게시본에서 제공해요. Outlook의 다른 첨부는 원본 메일에서 확인해요.

타임라인

어떤 일이 언제 있었는지 날짜순으로 봐요.

  1. 날짜를 따라 소식을 살펴봐요.
  2. 궁금한 제목을 누르면 관련 글이 열려요.
  3. 옛날 일부터 보려면 최신순을 오래된순으로 바꿔요.

계획은 앞으로 하려는 일이에요. 보고일은 소식을 전한 날짜예요.

원하는 기간만 보기

검색 조건에서 시작일과 종료일을 고르면 그 기간의 리포트에서 정리한 일을 볼 수 있어요. 데일리리포트에서 쓰던 검색어와 조건도 그대로 적용돼요.

보고 싶은 내용이 안 보이면 초기화를 눌러 다시 살펴보세요.

관계

회사와 회사가 어떻게 이어져 있는지 봐요.

  1. 회사 이름과 그 사이의 선을 찾아봐요.
  2. 이름이나 선을 눌러요.
  3. 옆에 나온 설명과 원문을 읽어요.

그림이 비어 있으면, 그 조건에 맞게 정리된 관계가 아직 없는 거예요.

어떤 자료인지 확인하기

위쪽의 Outlook · 데일리 리포트 · 내 자료 · 내 노트를 켜거나 끄면 보고 싶은 자료만 남길 수 있어요.

선을 눌러 연결된 이유와 근거를 읽어 보세요. 노트·PDF·메일이 리포트에 연결된 것과, 회사끼리 협력한 것은 서로 다른 연결이에요.

지도

글과 자료가 이어진 모습을 한눈에 봐요.

  1. 동그라미에 적힌 이름을 살펴봐요.
  2. 회사·분류·리포트를 누르면 오른쪽에 관련 자료 목록이 나와요. 목록에서 자료를 열고 관련 자료 목록으로 돌아올 수 있어요.
  3. 빈 곳을 누른 채 움직이면 그림이 이동해요. 마우스 바퀴를 굴리면 커지거나 작아져요.

여기서 지도는 자료 사이의 연결을 그린 그림이에요.

그림이 복잡할 때

검색어나 검색 조건으로 범위를 좁혀 보세요. 위쪽의 Outlook · 데일리 리포트 · 내 자료 · 내 노트로 표시할 자료도 고를 수 있어요.

표시할 자료를 바꾸면 관계 탭에도 함께 적용돼요. 모두 끄면 그림이 비어 있으니, 보고 싶은 자료를 하나 이상 켜 주세요.

Outlook

메일로 받은 리포트를 모아 보는 곳이에요.

처음 연결한다면 메일함 연결 순서 또는 PST 파일 연결 순서부터 따라 하세요. GitHub가 연결되어 있지 않아도 사용할 수 있어요.

  1. 메일함에서 리포트 가져오기를 펼쳐요.
  2. Outlook 메일함 불러오기를 누르고, 원하는 메일함의 폴더 선택을 눌러요.
  3. 원하는 폴더 옆의 이 폴더 추가를 눌러요. 가져온 글은 아래 목록에서 읽어요.

클래식 Outlook이 있어야 해요. 리포트 본문·MD 첨부와 전달된 원본 메일(.msg) 안의 MD를 읽어요. 이전 데일리 형식도 지원해요.

가져온 뒤에는

선택한 폴더를 실행 직후와 5분마다 확인해요. 바로 확인하려면 지금 가져오기를 눌러요. 하위 폴더는 각각 선택해야 해요. 메일 제목·보낸 사람·폴더 이름으로 검색할 수 있어요.

v0.1.9의 .msg 지원을 처음 적용하면 기존 폴더를 한 번 다시 검사해요. 메일이 많으면 몇 분 이상 걸릴 수 있어요. 완료한 진행 위치를 기억해요.

중복·제외에는 일반 메일과 같은 내용도 포함돼요. MD 형식 확인 필요는 파일을 읽었지만 리포트 양식이 아니라는 뜻이에요. 읽지 못한 메일은 다음 확인 때 다시 시도해요. 일반 Markdown 문서는 노트의 MD 가져오기를 이용해요.

리포트를 연 뒤 Outlook 원문 열기를 누르면 원래 메일을 볼 수 있어요. 데일리리포트에 같은 글이 있어도, 이곳에서는 메일에서 가져온 원본을 볼 수 있어요.

PST 파일은 경로 추가로 고른 뒤 폴더 선택 → 이 폴더 추가까지 진행해요. OST는 현재 Outlook에 설정된 메일함만 지원해요. 연결 해제를 눌러도 원래 메일과 이미 가져온 리포트는 남아요.

내 자료

내 PDF 문서를 넣어 두는 서랍이에요.

  1. PDF 추가를 누르고 보관할 파일을 골라요.
  2. 목록에서 파일 이름을 누르면 문서가 보여요.
  3. 작게 보이면 크게 보기를 눌러요.

보관한 사본은 이 PC에 잠가 두어요. 여기서 삭제한 PDF 사본은 되돌릴 수 없어요.

PDF를 리포트와 연결하기

파일 옆의 연결 리포트를 누르거나, 파일을 연 뒤 연결할 리포트를 골라 연결을 눌러요.

제목이 같으면 게시 리포트 · Outlook · 직접 가져온 MD 표시를 보고 골라요. 연결된 제목을 누르면 그 리포트를 읽을 수 있어요.

해제는 리포트와의 연결만 끊어요. PDF 파일은 내 자료에 그대로 남아요.

노트

리포트를 읽으며 떠오른 생각을 Markdown으로 기록하세요.

  1. 새 노트에서 제목과 본문을 쓰면 자동 저장됩니다.
  2. 원문·분할·읽기·Live Preview를 선택하고, 캡처를 붙여넣으세요.
  3. [[노트 이름]]이나 연결된 리포트로 관련 내용을 모아 보세요.

입력을 마친 뒤 저장 완료를 확인하세요. 지금 저장이나 Ctrl+S로 즉시 저장할 수 있어요. 노트는 이 PC의 평문 .md 파일입니다.

기존 문서와 저장 위치

MD 가져오기로 일반 Markdown 문서도 넣을 수 있어요. 저장 폴더를 바꾸면 그 위치의 노트를 열고, 기존 파일은 원래 폴더에 남겨요.

휴지통에서 삭제한 노트를 복원하고 이전 저장본에서 최근 저장 내용을 되돌릴 수 있어요. 외부 편집기와 내용이 충돌하면 변경 내용 비교를 확인하세요.

노트의 연결 보기

관계와 지도에서 내 노트를 켜세요. [[노트 이름]]과 직접 연결한 리포트가 선으로 이어집니다. 연결 없는 노트도 지도에 표시돼요.

노트를 누르면 미리보기와 노트 열기 · 편집이 나옵니다. 선을 누르면 어떤 본문 링크로 연결됐는지 확인할 수 있어요.

AI 검색

필요할 때만

올려 둔 문서와 그림에서 비슷한 내용을 찾아요.

  1. 처음에는 환경 설정 안내를 따라 준비하고 검색 서비스 시작을 눌러요.
  2. PDF·이미지 추가로 파일을 고르거나 자료 목록에 놓아요. 파일당 최대 50MB예요.
  3. 찾고 싶은 내용을 문장으로 쓰고 검색을 눌러요. 나온 결과를 눌러 내용을 봐요.예: 운전자가 없는 자동차

준비가 어려우면 담당자에게 도움을 요청해요. 올린 사본은 잠금 없이 저장되니, 회사의 중요한 자료는 올리지 마세요.

언제 쓰면 좋을까요?

정확한 단어가 생각나지 않을 때, 찾고 싶은 내용을 문장으로 써 보세요. 올린 PDF와 그림에서 비슷한 내용을 찾아줘요.

왼쪽에서 자료나 검색 결과를 고르면 오른쪽에 해당 페이지나 그림이 보여요. 색인·모델 정보에서 상세 상태를 확인할 수 있어요.

검색 모델은 이 PC에서 실행해요. 환경 설정을 처음 할 때 모델과 패키지를 내려받으며 Python이 별도로 필요해요. AI 검색을 준비하지 않아도 다른 탭은 그대로 사용할 수 있어요.

설정

화면을 바꾸거나 숨긴 글을 다시 꺼내요.

  • 화면 색을 바꾸려면 화면 스타일에서 골라요. 바로 바뀌어요.
  • 삭제한 리포트를 다시 보려면 삭제한 리포트 복원에서 글을 고르고 선택 복원을 눌러요.
  • 새 자료를 받으려면 자료 연결 · 자동 업데이트에서 GitHub 자료 연동을 켜요. 확인할 시간을 정한 뒤 검사하고 저장을 눌러요.

리포트 목록의 삭제는 글을 숨기는 거예요. 여기서 다시 꺼낼 수 있어요.

버전 확인과 프로그램 업데이트

실행 중인 버전은 앱 상단·설정·도움말에서 확인해요. 프로그램을 바꾸려면 새 AVReportHub-Setup.exe를 실행하세요. 지금 업데이트는 리포트 자료만 확인하며 프로그램을 교체하지 않아요.

새 버전을 처음 실행하면 GitHub 연동 여부를 한 번 선택해요. 연동하지 않아도 Outlook·MD·PDF·노트는 사용할 수 있어요.

자료 연결과 프로그램 종료

GitHub는 새 리포트를 받아오는 보관소예요. 연동을 켜고 연결에 성공하면 GitHub 리포트를 받아 표시해요. 연동을 끄거나 연결에 실패하면 GitHub 리포트는 목록에서 빠져요. Outlook·직접 가져온 자료는 계속 볼 수 있어요.

브라우저 창만 닫으면 프로그램은 계속 실행돼요. 자동 업데이트도 멈추려면 왼쪽 아래의 종료를 눌러요.

이 도움말 탭을 닫으면, 보던 리포트가 그대로 있어요.
