데일리리포트

여기부터

궁금한 소식을 찾아 읽는 곳이에요.

  1. 위쪽 검색칸에 회사 이름이나 궁금한 말을 써요.예: 현대차
  2. 목록에서 제목을 누르면 글이 열려요.
  3. 너무 많이 나오면 검색 조건에서 회사나 날짜를 골라요.

검색어와 검색 조건을 지우려면 초기화를 눌러요.

내 리포트도 함께 보기

가져오기로 정해진 양식의 MD 리포트 파일을 넣을 수 있어요. Outlook에서 가져온 리포트도 여기에 모여요. 같은 내용은 한 번만 보여요.

목록의 삭제는 글을 숨기는 기능이에요. 다시 보고 싶으면 설정 → 삭제한 리포트 복원을 이용해요.

새로 올라온 글을 받으려면 위쪽의 지금 업데이트를 눌러요. 버튼이 꺼져 있으면 설정에서 GitHub 자료 연동을 켜고 저장해요.

타임라인

어떤 일이 언제 있었는지 날짜순으로 봐요.

  1. 날짜를 따라 소식을 살펴봐요.
  2. 궁금한 제목을 누르면 관련 글이 열려요.
  3. 옛날 일부터 보려면 최신순을 오래된순으로 바꿔요.

계획은 앞으로 하려는 일이에요. 보고일은 소식을 전한 날짜예요.

원하는 기간만 보기

검색 조건에서 시작일과 종료일을 고르면 그 기간의 리포트에서 정리한 일을 볼 수 있어요. 데일리리포트에서 쓰던 검색어와 조건도 그대로 적용돼요.

보고 싶은 내용이 안 보이면 초기화를 눌러 다시 살펴보세요.

관계

회사와 회사가 어떻게 이어져 있는지 봐요.

  1. 회사 이름과 그 사이의 선을 찾아봐요.
  2. 이름이나 선을 눌러요.
  3. 옆에 나온 설명과 원문을 읽어요.

그림이 비어 있으면, 그 조건에 맞게 정리된 관계가 아직 없는 거예요.

어떤 자료인지 확인하기

위쪽의 Outlook · 데일리 리포트 · 내 자료 · 내 노트를 켜거나 끄면 보고 싶은 자료만 남길 수 있어요.

선을 눌러 연결된 이유와 근거를 읽어 보세요. 노트·PDF·메일이 리포트에 연결된 것과, 회사끼리 협력한 것은 서로 다른 연결이에요.

지도

글과 자료가 이어진 모습을 한눈에 봐요.

  1. 동그라미에 적힌 이름을 살펴봐요.
  2. 회사 이름을 누르면 관련 글을 모아 봐요. 글을 누르면 본문이 열려요.
  3. 빈 곳을 누른 채 움직이면 그림이 이동해요. 마우스 바퀴를 굴리면 커지거나 작아져요.

여기서 지도는 자료 사이의 연결을 그린 그림이에요.

그림이 복잡할 때

검색어나 검색 조건으로 범위를 좁혀 보세요. 위쪽의 Outlook · 데일리 리포트 · 내 자료 · 내 노트로 표시할 자료도 고를 수 있어요.

표시할 자료를 바꾸면 관계 탭에도 함께 적용돼요. 모두 끄면 그림이 비어 있으니, 보고 싶은 자료를 하나 이상 켜 주세요.

Outlook

메일로 받은 리포트를 모아 보는 곳이에요.

  1. 메일함에서 리포트 가져오기를 펼쳐요.
  2. Outlook 메일함 불러오기를 누르고, 원하는 메일함의 폴더 선택을 눌러요.
  3. 원하는 폴더 옆의 이 폴더 추가를 눌러요. 가져온 글은 아래 목록에서 읽어요.

클래식 Outlook이 있어야 해요. 정해진 리포트 양식의 메일만 가져와요.

가져온 뒤에는

선택한 폴더에서 리포트를 자동으로 가져와요. 바로 확인하고 싶으면 지금 가져오기를 눌러요. 메일 제목이나 보낸 사람, 폴더 이름으로 찾을 수도 있어요.

리포트를 연 뒤 Outlook 원문 열기를 누르면 원래 메일을 볼 수 있어요. 데일리리포트에 같은 글이 있어도, 이곳에서는 메일에서 가져온 원본을 볼 수 있어요.

따로 받은 PST·OST 메일 보관 파일은 경로 추가로 골라 연결해요. 연결 해제를 눌러도 원래 메일과 이미 가져온 리포트는 남아요.

내 자료

내 PDF 문서를 넣어 두는 서랍이에요.

  1. PDF 추가를 누르고 보관할 파일을 골라요.
  2. 목록에서 파일 이름을 누르면 문서가 보여요.
  3. 작게 보이면 크게 보기를 눌러요.

보관한 사본은 이 PC에 잠가 두어요. 여기서 삭제한 PDF 사본은 되돌릴 수 없어요.

PDF를 리포트와 연결하기

파일 옆의 연결을 누르거나, 파일을 연 뒤 연결할 리포트를 골라 연결을 눌러요.

제목이 같으면 게시 리포트 · Outlook · 직접 가져온 MD 표시를 보고 골라요. 연결된 제목을 누르면 그 리포트를 읽을 수 있어요.

해제는 리포트와의 연결만 끊어요. PDF 파일은 내 자료에 그대로 남아요.

노트

리포트를 읽으며 떠오른 생각을 Markdown으로 기록하세요.

  1. 새 노트에서 제목과 본문을 쓰면 자동 저장됩니다.
  2. 원문·분할·읽기·Live Preview를 선택하고, 캡처를 붙여넣으세요.
  3. [[노트 이름]]이나 연결된 리포트로 관련 내용을 모아 보세요.

노트는 이 PC의 평문 .md 파일입니다. 저장 폴더 변경, 태그·검색, 휴지통과 이전 저장본 복구를 지원합니다.

노트의 연결 보기

관계와 지도에서 내 노트를 켜세요. [[노트 이름]]과 직접 연결한 리포트가 선으로 이어집니다. 연결 없는 노트도 지도에 표시돼요.

노트를 누르면 미리보기와 노트 열기 · 편집이 나옵니다. 선을 누르면 어떤 본문 링크로 연결됐는지 확인할 수 있어요.

AI 검색

필요할 때만

올려 둔 문서와 그림에서 비슷한 내용을 찾아요.

  1. 처음에는 환경 설정 안내를 따라 준비하고 검색 서비스 시작을 눌러요.
  2. PDF나 그림 파일을 골라 올려요.
  3. 찾고 싶은 내용을 문장으로 쓰고 검색을 눌러요. 나온 결과를 눌러 내용을 봐요.예: 운전자가 없는 자동차

준비가 어려우면 담당자에게 도움을 요청해요. 올린 사본은 잠금 없이 저장되니, 회사의 중요한 자료는 올리지 마세요.

언제 쓰면 좋을까요?

정확한 단어가 생각나지 않을 때, 찾고 싶은 내용을 문장으로 써 보세요. 올린 PDF와 그림에서 비슷한 내용을 찾아줘요.

결과를 누르면 해당 페이지나 그림을 확인할 수 있어요. AI 검색을 준비하지 않아도 다른 탭은 그대로 사용할 수 있어요.

설정

화면을 바꾸거나 숨긴 글을 다시 꺼내요.

  • 화면 색을 바꾸려면 화면 스타일에서 골라요. 바로 바뀌어요.
  • 삭제한 리포트를 다시 보려면 삭제한 리포트 복원에서 글을 고르고 선택 복원을 눌러요.
  • 새 자료를 받으려면 자료 연결 · 자동 업데이트에서 GitHub 자료 연동을 켜요. 확인할 시간을 정한 뒤 검사하고 저장을 눌러요.

리포트 목록의 삭제는 글을 숨기는 거예요. 여기서 다시 꺼낼 수 있어요.

자료 연결과 프로그램 종료

GitHub는 새 리포트를 받아오는 보관소예요. 연동을 켜고 연결에 성공하면 GitHub 리포트를 받아 표시해요. 연동을 끄거나 연결에 실패하면 GitHub 리포트는 목록에서 빠져요. Outlook·직접 가져온 자료는 계속 볼 수 있어요.

브라우저 창만 닫으면 프로그램은 계속 실행돼요. 자동 업데이트도 멈추려면 왼쪽 아래의 종료를 눌러요.

이 도움말 탭을 닫으면, 보던 리포트가 그대로 있어요.
