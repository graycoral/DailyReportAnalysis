# Executive Summary
## 2026-10-22 · Bolt·NVIDIA 마드리드 L4 검증·Tesla 안전보고

- **[신규·계획] Bolt:** NVIDIA Alpamayo Stack을 유럽 로보택시 프로그램에 선정했고, 규제 승인을 전제로 2027년 마드리드에서 실도로 데이터 수집을 시작할 계획이다.[R1][R2]
- **[신규·공식 공개] Tesla:** 안전요원 없는 자율 운행만 집계한 첫 Robotaxi Safety Report를 공개했다. 1월 22일~10월 18일 고정 집계는 3,112,541마일이다.[R3][R4]
- **[신규·계획] Tesla:** 실적 설명회에서 운전석·안전요원 없는 Cybercab을 11월 Dallas에 투입하겠다고 밝혔다. 기존 Dallas Model Y 서비스와 구분되는 차량 플랫폼 확대 계획이다.[R5][R6]
- **구분:** Bolt의 Madrid 단계는 개발·검증용 데이터 수집 계획이며 상용 또는 무인 운행 개시가 아니다. Tesla 안전 수치는 회사 자체 정의에 따른 공개치다.[R1][R3]
- **지정 6개사:** Uber는 NVIDIA와 AV 데이터 팩토리 개발 사실, Bolt는 Alpamayo 선정·Madrid 계획을 신규 확인했다. Avride·Mobileye·카카오모빌리티·쏘카는 신규 확인 사항 없음.[R1][R7][R8][R9][R10][R11]
- **May Mobility [중복] · 이전 보고 2026-10-21:** 신규 확인 사항 없음. 실제 지역·안전요원·차량 실적·SPAC 일정을 재점검했다.[R12][R13][R14][R15][R17]

확인 기준: **2026-10-22 한국시간 아침**. 이전 발송본과 대조해 동일 사건·수치의 재보도를 제외했다.

# 주요 신규 업데이트
## [신규] Bolt·NVIDIA 검증 계획 / Tesla 안전 공개

- **발표일 2026-10-21 · Bolt·NVIDIA·Madrid:** Bolt는 Lucid의 향후 Hyperion 기반 차량부터 Alpamayo Stack을 적용하고, 유럽 도로용 소프트웨어를 NVIDIA와 공동 조정할 계획이다.[R1][R2]
- **예정 시점:** 2027년 Madrid 실도로 데이터 수집은 규제 승인 조건이다. Germany는 이후 배치 우선 지역으로 제시됐지만 상용 개시일·허가·차량 수는 공개되지 않았다.[R1]
- **Tesla 공개일 2026-10-21:** 공식 보고서는 안전요원이 없고 원격 지원 또는 원격 제어가 있었던 자율주행까지 집계하며, 2026년 1월 22일~10월 18일을 고정 결과 구간으로 삼는다.[R3]
- **고정 수치:** 3,112,541마일이며 Austin 2,118,015마일, Dallas 608,130마일, Houston 225,964마일 등 6개 도시를 포함한다.[R4][R6]
- **확인 한계:** Tesla의 ‘부상자 0’은 Robotaxi가 최초 접촉한 충돌만 포함하고, 사람 운전자 비교는 Texas 경찰 자료 기반이다. 전체 충돌 0을 의미하지 않는다.[R3]

# 기업/지역별 상세 내용
## Bolt·Madrid / Tesla·미국

- **Bolt 기술 범위:** NVIDIA는 다수 제조사 차량에 Alpamayo를 통합하고 Bolt의 차량 운영·시장 역량을 결합한다고 밝혔다. 2만5천대 Lucid 계획은 9월 기보고 내용이며 오늘의 신규는 스택 선정과 Madrid 검증 시점이다.[R1][R2]
- **Bolt 운영 단계:** 2027년 실제 승객 영업이 아니라 개발·검증을 위한 실도로 데이터 수집 계획이다. 안전요원 유무와 무인 전환 일정은 발표하지 않았다.[R1]
- **Tesla 운행 범위:** 안전 보고서는 Austin·Dallas·Houston·Miami·Orlando·Tampa의 안전요원 없는 구간을 집계하고, Bay Area 안전운전자 운행은 제외한다.[R3][R6]
- **Tesla Dallas:** 11월 계획은 목적형 Cybercab의 Dallas 투입이다. Dallas 지역 자체는 이미 Model Y 무인 서비스를 운영 중이라고 별도 보도가 설명한다.[R6]
- **예정 도시:** Tesla 안전 페이지는 Las Vegas·Jacksonville·Phoenix·San Antonio를 ‘Coming Soon’으로 표시했으나 개시일과 초기 안전요원 조건은 공개하지 않았다.[R4][R6]

# 규제·안전

- **Bolt:** Madrid 실도로 데이터 수집은 규제 승인 조건이다. 독일 우선 배치도 계획 단계이며 허가·무인 상용 운행 달성으로 해석하지 않는다.[R1]
- **Tesla 집계 정의:** 안전요원 없는 상태에서 ADS가 충돌 전 30초 내 작동한 모든 NHTSA SGO 보고 충돌을 포함하며, 원격 지원·원격 제어 구간도 포함한다.[R3]
- **Tesla 지표 한계:** ‘부상자’와 보행자·자전거 충돌은 Robotaxi가 최초 접촉한 경우로 정의한다. 사람 운전자 벤치마크는 최초 접촉 여부를 구분하지 못해 직접 비교에 한계가 있다.[R3]
- **미확인:** Bolt의 Madrid 안전요원 구성과 Tesla 신규 4개 도시의 개시일·초기 안전요원 조건은 공개되지 않았다.[R1][R6]
