# 멀티모달 검색 (실험 기능) 안내

PDF 페이지와 이미지 파일을 **이미지 그대로** 임베딩해서 문장으로 찾는 기능입니다. 표·차트·슬라이드·사진·스크린샷도 검색할 수 있습니다. 임베딩 모델은 Google의 `embeddinggemma-2`를 **내 PC에서 직접** 실행하며 외부 AI 서비스를 호출하지 않습니다.

> **모델과 Python은 기본 배포본에 포함되지 않습니다.** 멀티모달 검색은 분석 담당자가 자기 PC에서 직접 환경을 설정하고 서비스를 켜는 선택 기능입니다. 탭에서 설정 상태를 확인하고 필요한 패키지와 모델을 준비할 수 있습니다. 검색·타임라인·그래프 등 기본 화면과 GitHub 동기화에는 영향이 없습니다.

## 1. 구조

```
AV Report Hub (Go EXE)  ──프록시──▶  rag/rag_server.py (Python, 127.0.0.1)  ──▶  embeddinggemma-2 (CPU)
        │                                     │
   🧪 멀티모달 검색 탭           %LOCALAPPDATA%\AVReportHub\rag\index  (PDF 사본·페이지 이미지·벡터, 암호화 없음)
```

- Go 앱에는 모델이나 Python 실행기가 들어 있지 않습니다. 선택 기능의 Python 소스만 포함되며, 환경 설정을 누르면 앱 데이터 폴더에 풀어 별도의 가상환경을 준비합니다. 검색 요청은 `rag-service.json`의 주소와 키로 로컬 서비스에 전달합니다.
- 서비스는 루프백(127.0.0.1)에만 열리고, 앱이 보내는 키가 없는 요청은 거부합니다.
- 오디오 인코더는 불러오지 않습니다. 텍스트+이미지 구성으로 약 4.4억 파라미터입니다.

## 2. 앱에서 환경 설정

1. AV Report Hub의 **🧪 멀티모달 검색** 탭을 엽니다.
2. **환경 설정**을 누릅니다. 전용 가상환경, CPU용 PyTorch, PDF·임베딩 패키지, 검색 모델을 순서대로 준비합니다. 첫 설정은 인터넷 연결과 여유 공간 5GB 이상이 필요하며 몇 분 이상 걸릴 수 있습니다.
3. Python이 없으면 **Python 공식 설치 페이지 열기**를 통해 python.org의 **Python 3.10 64비트**를 설치하고 **환경 설정 다시 시도**를 누릅니다. 앱은 Python 자체를 설치하거나 기존 Python 설정을 변경하지 않습니다.
4. 모델을 실제로 불러와 이미지와 문장 임베딩을 검증하면 **환경 설정 완료**가 표시됩니다.
5. **검색 서비스 시작**을 누릅니다. **서비스 실행 중**으로 바뀌면 PDF를 올려 검색할 수 있습니다.

환경 준비와 서비스 실행은 별도 상태입니다. 서비스가 꺼져도 검증된 환경은 유지됩니다. 앱을 다시 열면 저장된 환경을 오프라인으로 검증하며, 확인 중에는 완료로 표시하지 않습니다. 앱이 시작한 서비스는 앱을 종료하면 함께 종료되며, 다음 실행 때 다시 시작할 수 있습니다. 별도로 실행한 기존 서비스도 연결되면 **환경 설정 완료**로 표시됩니다.

설정 중에는 단계별 진행 문구가 표시되고 중복 실행이 차단됩니다. 실패하면 해당 단계의 안내를 확인하고 다시 시도할 수 있습니다. 작업 중 앱을 종료하면 설정이 중단되므로 다음 실행 때 다시 설정해 주세요. 탭을 여는 것만으로 패키지나 모델을 다운로드하지 않습니다.

앱이 관리하는 파일은 기본적으로 다음 위치에 저장됩니다. `--data-dir`를 사용하면 해당 앱 데이터 폴더 아래에 저장합니다.

- `%LOCALAPPDATA%\AVReportHub\rag\runtime`: 서비스 소스, 전용 `.venv`, 환경 검증 기록
- `%LOCALAPPDATA%\AVReportHub\rag\models`: 모델 캐시
- `%LOCALAPPDATA%\AVReportHub\rag\index`: PDF 사본·페이지 이미지·벡터
- `%LOCALAPPDATA%\AVReportHub\rag\demo`: 데모 PDF

앱 데이터 폴더가 Git 저장소 안에 있으면 환경 설정과 서비스 시작을 거부합니다. 기존 수동 실행 환경과 앱 전용 가상환경은 별개입니다.

## 3. 수동 준비 (선택)


필요한 것: Windows 10/11 64비트, **Python 3.10** (python.org 배포판), 인터넷(모델 내려받기 약 1~2GB), 디스크 5GB, 메모리 8GB 이상.

```powershell
cd DailyReportAnalysis\rag
py -3.10 -m venv .venv
.\.venv\Scripts\python -m pip install --upgrade pip
.\.venv\Scripts\python -m pip install torch --index-url https://download.pytorch.org/whl/cpu
.\.venv\Scripts\python -m pip install -r requirements.txt
```

> Miniconda의 Python 3.12로 가상환경을 만들면 이 PC에서는 `torch` 로딩이 `WinError 1114 (c10.dll)`로 실패했습니다. python.org의 3.10을 쓰세요.

모델을 받고 동작을 확인합니다.

```powershell
.\.venv\Scripts\python test_embed.py
```

처음 실행하면 Hugging Face에서 모델을 내려받습니다(Apache 2.0, 로그인 불필요). 끝나면 아래 항목이 출력됩니다.

- 모델 불러오는 시간, 파라미터 수, 임베딩 차원(768)
- 데모 폴더 첫 PDF의 첫 페이지를 이미지로 바꿔 임베딩한 시간
- 그 페이지와 문장 3개(관련 2, 무관 1)의 코사인 유사도

기본 데모 폴더는 `%LOCALAPPDATA%\AVReportHub\rag\demo`입니다. 소스 저장소에서 실행할 때 이 폴더에 PDF가 없으면 최신 리포트로 샘플 PDF를 만듭니다. 실제 PDF를 시험하려면 `--docs 경로`를 붙이며, Git 저장소 밖의 폴더를 사용해야 합니다. 이 검사는 첫 페이지 검증이며 검색용 전체 색인은 앱에서 PDF를 올려야 생성됩니다.

## 4. 수동 서비스 실행과 검색

1. 서비스를 켭니다. 창을 닫으면 꺼집니다.
   ```powershell
   cd DailyReportAnalysis\rag
   .\.venv\Scripts\python rag_server.py
   ```
   "model ready …", "listening on http://127.0.0.1:…"가 보이면 준비된 것입니다.
2. AV Report Hub를 실행하고 **🧪 멀티모달 검색** 탭을 엽니다. 서비스를 나중에 켰다면 "다시 확인"을 누릅니다.
3. **보여 줘** 버튼: 모델 정보, 첫 페이지 임베딩 시간, 문장 유사도를 표로 보여줍니다. "다시 계산"은 처음부터 다시 잽니다.
4. **PDF·이미지 올리기**: 끌어다 놓거나 눌러서 선택합니다. PDF, PNG, JPG/JPEG/JFIF, WebP, GIF, BMP, TIFF, AVIF, HEIC/HEIF, ICO를 지원합니다(파일당 50MB). PDF·TIFF는 모든 페이지, 움직이는 이미지와 HEIC 묶음은 첫 프레임을 색인합니다. 사진의 회전 정보와 투명 배경도 반영합니다. 손상된 파일이나 지원하지 않는 형식은 오류를 표시합니다. 올리기 전에 경고 창이 뜹니다(아래 참고).
5. **검색**: 문장을 입력하면 가장 비슷한 페이지 6개가 썸네일과 유사도로 나옵니다. 썸네일을 누르면 오른쪽에 크게 표시됩니다.
6. 색인된 문서는 목록에서 **삭제**할 수 있습니다. 사본·이미지·벡터가 함께 지워집니다.
7. **전체 지도에서 보기**: 색인한 PDF·이미지는 전체 지도에 이 PC의 자료 노드로 자동 표시됩니다. 파일을 선택하면 페이지 미리보기를 넘겨 볼 수 있습니다. 검색어는 파일명에도 적용되며 기업·분류·기간 필터는 게시된 리포트에 적용됩니다.

지도에는 두 자료의 페이지 이미지 중 가장 높은 코사인 유사도가 0.6 이상인 연결을 자료마다 최대 3개 표시합니다. 주황색 점선을 선택하면 파일명, 비교 페이지, 유사도 점수를 확인합니다. 이 연결은 검색 모델의 유사도이며, 기존 기업·사건의 확인된 관계가 아닙니다. 기업·사건 관계나 게시된 catalog에 자동 편입하지 않으며, 원본·벡터·지도 자료는 GitHub에 동기화하지 않습니다. 서비스를 끄면 지도에는 게시된 리포트만 표시되고, 다시 켠 뒤 **색인 자료 새로고침**으로 불러올 수 있습니다.

## 5. 올리기 전 경고 창에 대해

PDF·이미지를 올릴 때마다 아래 내용을 확인하는 창이 뜹니다. "이 세션에서는 다시 묻지 않기"를 켜면 앱을 다시 열 때까지 생략됩니다.

- PDF·이미지는 이 PC의 임베딩 서비스로 전송되어 페이지 이미지와 벡터로 바뀝니다.
- 사본과 변환 결과는 `%LOCALAPPDATA%\AVReportHub\rag\index`에 **암호화 없이** 저장됩니다. 「내 자료」 탭의 PDF처럼 Windows 계정으로 암호화되지 않습니다.
- 저장 폴더는 Git 저장소 밖에 있으며, `RAG_INDEX`·`RAG_DOCS`로 저장소 안을 지정하면 서비스가 시작을 거부합니다. 예전 위치 `rag/index/`에 남은 색인은 첫 실행 때 옮겨집니다.
- 이 폴더가 OneDrive 같은 동기화·백업 대상이면 **외부로 유출될 수 있습니다**. 그런 경로는 막지 못합니다.
- 회사 정책상 반출 금지 문서는 올리지 마세요.

## 6. 「내 자료」와의 차이

| | 🔒 내 자료 | 🧪 멀티모달 검색 |
| --- | --- | --- |
| 목적 | 리포트에 PDF·메일을 붙여 두기 | PDF 페이지를 내용으로 찾기 |
| 저장 | DPAPI 암호화, `%LOCALAPPDATA%\AVReportHub\docs\pdf` | 평문, `%LOCALAPPDATA%\AVReportHub\rag\index` |
| 검색 | 파일 이름 | 페이지 이미지 임베딩 (문장으로) |
| AI 실행 | 없음 | 내 PC에서 embeddinggemma-2 |
| 배포본 포함 | 예 | 설정 UI·서비스 소스 포함, 모델·Python 실행기는 별도 준비 |

## 7. 문제 해결

| 증상 | 조치 |
| --- | --- |
| Python 3.10이 필요하다고 표시 | 공식 64비트 Python을 설치하고 환경 설정을 다시 시도하세요. Miniconda 환경은 자동 설정에서 사용하지 않습니다 |
| 환경 확인 또는 설정 실패 | 표시된 단계의 안내에 따라 연결·디스크 공간·폴더 권한을 확인하고 환경 설정을 다시 실행하세요 |
| 환경 설정 완료인데 서비스 꺼짐 | **검색 서비스 시작**을 누르세요. 설치 완료와 서비스 실행은 별도 상태입니다 |
| 탭에 "서비스가 실행 중이 아닙니다" | `rag_server.py`가 켜져 있는지, 같은 Windows 계정인지 확인. `%LOCALAPPDATA%\AVReportHub\rag-service.json`이 있어야 합니다 |
| `WinError 1114` c10.dll | Miniconda Python으로 만든 가상환경입니다. python.org 3.10으로 다시 만드세요 |
| 모델 내려받기 실패 | 프록시·방화벽에서 `huggingface.co` 허용. 처음 한 번만 내려받고, 이후에는 캐시된 모델을 먼저 써서 외부 접속 없이 시작합니다(문서는 전송하지 않음, 사용 통계 전송 끔) |
| 색인이 너무 느림 | CPU 전용입니다. 환경변수 `RAG_RENDER_SCALE=1.0`으로 해상도를 낮추면 빨라집니다 |
| 첫 페이지 유사도가 모두 낮음 | 스캔 품질이나 페이지 내용이 적을 때 그렇습니다. 문장을 더 구체적으로 쓰세요 |

수동 실행 서비스의 로그는 콘솔에만 출력됩니다. 앱에서 실행한 환경 작업은 설치 도구의 원시 로그를 저장·노출하지 않으며 단계별 상태와 오류 안내만 표시합니다.
