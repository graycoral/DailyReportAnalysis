# AV Report Hub v0.1.9 · 2026-10-19

- 현대자동차 CI의 현대 블루·라이트 샌드·스카이 블루를 바탕으로 세 화면 스타일을 정리했습니다. 버튼·선택 표시·도움말에 같은 색상을 적용하고 다크 모드의 버튼과 스위치 대비를 보완했습니다.

- 앱과 도움말의 브라우저 탭 아이콘을 실행 파일·바탕화면 바로가기와 같은 AV 아이콘으로 통일했습니다.

- 사용자 가이드와 앱 내 도움말을 현재 9개 화면에 맞춰 정리했습니다. 앱 상단·설정·도움말에서 실행 중인 버전을 확인할 수 있습니다.

- Outlook 전달 메일의 원본 `.msg` 안에 들어 있는 MD도 가져옵니다. 예전 데일리 형식과 여러 슬라이드로 나뉜 섹션을 인식하며, 이미 확인한 선택 폴더를 한 번 다시 검사합니다. 형식 오류와 읽기 실패를 구분해 표시하고 읽지 못한 메일은 다음 확인 때 재시도합니다.

# AV Report Hub v0.1.8

- **노트**: 실제 Markdown 파일 자동 저장, 원문·분할·읽기·Live Preview, 이미지 붙여넣기, 폴더·태그·검색, 리포트 및 노트 연결, 역참조를 추가했습니다. 외부 편집 변경 감지·충돌 비교와 사본 저장, 휴지통, 최근 50개 저장본 복구를 지원합니다. 편집기는 EXE에 포함되며 인터넷·별도 런타임 없이 동작합니다.
- **노트 연결 지도**: 본문에 작성한 노트 링크와 직접 저장한 리포트 연결을 관계 그래프·전체 지도에 표시합니다. 연결 근거와 원문을 확인하고 편집기로 이동할 수 있으며, 검색·표시 스위치·외부 파일 변경을 반영합니다.

- GitHub 연동 전에는 기본 리포트·DB를 자동으로 넣지 않습니다. 연동을 끄면 GitHub 리포트·사건·관계를 표시하지 않고 첨부 다운로드도 차단합니다. 기존 캐시는 보존하며 Outlook·수동 MD·PDF는 독립적으로 사용할 수 있습니다. 같은 보고일·본문의 리포트는 데일리 목록에서 한 번만 표시합니다.

- 모델·인터넷 없이 동작하는 **자료 연결**을 추가했습니다. 메일 대화, 동일 파일 지문, 문서·프로젝트 번호, 기업·프로젝트 사전과 제목 핵심어로 후보와 근거를 표시합니다. 확정·제외·판단 취소를 지원하며 확정한 연결만 관계·전체 지도에 표시합니다. 사전·판단·선택 폴더의 메일 메타데이터는 이 PC에 암호화 보관합니다.
- v0.1.8부터 새 버전 첫 실행에 GitHub 자료 연동 여부를 묻습니다. 버전 비교는 PC에 저장한 값으로 수행하며, 선택 전에는 GitHub 자동 연결을 보류합니다. 선택은 버전별로 저장되고 설정에서 변경할 수 있습니다.
- 설정에 `GitHub 자료 연동` 스위치를 추가했습니다. 연결 실패 시 자동으로 끄고 보관한 자료는 유지합니다.

- 내 자료의 PDF를 간결한 행으로 표시하고 파일명 옆에 `연결 리포트`와 실제 `삭제` 버튼을 제공합니다.
- 데일리리포트 탭에 문서 아이콘을 사용하고 목록의 `삭제`로 원본을 보관하면서 검색·관계·지도에서 숨깁니다. 설정에서 선택 복원과 전체 복원을 지원합니다.
- 상단 신호등으로 업데이트 상태를 표시하고 마지막 확인 시각과 `지금 업데이트` 버튼을 제공합니다. 스타일·연결 환경은 왼쪽 설정 탭에서 관리합니다.
- UTF-8 MD 드래그앤드롭 및 파일 선택으로 REPORT_FORMAT 리포트를 가져옵니다. 형식 검사, 중복 방지, 같은 날짜 갱신, 암호화 저장을 지원합니다.
- 클래식 Outlook에서 가져올 폴더를 선택합니다. 지정한 폴더의 REPORT_FORMAT 본문·MD 첨부만 리포트로 가져옵니다. 일반 메일은 자료 연결에 필요한 메타데이터·첨부 지문만 보관하며 본문·첨부 사본은 저장하지 않습니다. 리포트 태그는 폴더명과 메일 제목에서만 정합니다.
- 가져온 리포트는 공개 데이터와 별도로 보존합니다. 기존 공개 본문의 관계 근거를 로컬에서 교체한 본문에 붙이지 않습니다.

# AV Report Hub v0.1.7

- 멀티모달 검색에서 PDF 외에 PNG·JPG·WebP·GIF·BMP·TIFF·AVIF·HEIC·ICO를 색인합니다. 사진 회전·투명 배경을 처리하고 PDF·TIFF는 모든 페이지를 검색합니다.
- 색인한 PDF·이미지는 전체 지도에 자동 표시됩니다. 자료 사이의 유사도 연결을 선택하면 비교한 원본 페이지와 점수를 확인합니다. 기존 기업·사건 관계와 구분하고, 로컬 원본·벡터는 동기화하지 않습니다.
- 앱에서 검색 환경 설정과 서비스 시작 상태를 구분하고, 설치한 패키지·모델을 검증합니다. 모델과 Python은 EXE에 포함하지 않으며 서비스는 127.0.0.1에서만 실행됩니다.

# AV Report Hub v0.1.4

- **🔒 내 자료 탭**: PDF를 끌어다 넣어 리포트에 연결합니다. 파일은 현재 Windows 계정으로 암호화해 이 PC에만 보관하며 GitHub 동기화·게시와 무관합니다.
- **클래식 Outlook 연결**: 메일함이나 PST를 지정하면 리포트별로 관련 메일을 제안하고 연결·열기를 지원합니다. 메일 본문은 복사하지 않고 제목·보낸 사람·날짜·폴더와 Outlook ID만 암호화 저장합니다. New Outlook과 PowerShell 제한 모드는 지원하지 않습니다.
- **Setup 재실행 시 자동 종료**: 실행 중인 AV 리포트를 종료한 뒤 교체합니다. 업데이트 전에 프로그램을 직접 끌 필요가 없습니다.
- **테마 선택**: Apple 라이트(기본)·Apple 다크·클래식. 브라우저별로 기억됩니다.
- **검색 정확도**: 기업명이 "신규 확인 사항 없음" 줄에만 나오는 리포트는 검색·기업 필터·지도에서 제외합니다(해제 가능).
- **일일 자동 게시**: ChatGPT가 `data/reports/`에 리포트를 push하면 GitHub Actions가 catalog·DB를 재생성해 커밋합니다. 사용자 PC는 08:00 갱신으로 받습니다. 작성 규칙은 [리포트 작성·게시 규칙](REPORT_FORMAT.md)에 있습니다.
- `scripts/import-history.py`에 `--from-reports`(폴더 스캔)·`--if-changed` 모드를 추가했습니다. 기업 목록은 `data/companies.json`으로 분리했습니다.
- 비개발자용 [시작 안내](USER_GUIDE.md)를 추가했습니다. 설치·SmartScreen 경고 대처·화면별 사용법·자주 하는 질문을 그림과 함께 담았습니다.

실행 파일 자체 자동 업데이트와 코드 서명은 아직 제공하지 않습니다. 업데이트는 새 Setup을 다시 실행하면 됩니다.
