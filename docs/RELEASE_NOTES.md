# AV Report Hub v0.1.5

- **🧪 멀티모달 검색 (선택 기능)**: 분석 담당자가 자기 PC에서 `rag/rag_server.py`를 켜면 PDF 페이지를 이미지로 임베딩(`embeddinggemma-2`, CPU)해 문장으로 찾습니다. 배포본에는 모델·Python이 없고, 서비스가 없는 PC에서는 안내만 표시합니다. 자세한 내용은 [멀티모달 검색 안내](RAG_GUIDE.md)에 있습니다.
- 멀티모달 검색 색인은 `%LOCALAPPDATA%\AVReportHub\rag\index`에 저장합니다. Git 저장소 안을 지정하면 서비스가 시작을 거부하고, 예전 `rag/index/`는 첫 실행 때 옮깁니다. 모델은 캐시를 먼저 써서 평소에는 외부 접속 없이 시작합니다.
- 🔒 내 자료 PDF는 `%LOCALAPPDATA%\AVReportHub\docs\pdf`에 암호화해 보관합니다. 기존 파일은 자동으로 옮겨집니다.

# AV Report Hub v0.1.4

- **🔒 내 자료 탭**: PDF를 끌어다 넣어 리포트에 연결합니다. 파일은 현재 Windows 계정으로 암호화해 이 PC에만 보관하며 GitHub 동기화·게시와 무관합니다.
- **클래식 Outlook 연결**: 메일함이나 PST를 지정하면 리포트별로 관련 메일을 제안하고 연결·열기를 지원합니다. 메일 본문은 복사하지 않고 제목·보낸 사람·날짜·폴더와 Outlook ID만 암호화 저장합니다. New Outlook과 PowerShell 제한 모드는 지원하지 않습니다.
- **Setup 재실행 시 자동 종료**: 실행 중인 AV 리포트를 종료한 뒤 교체합니다. 업데이트 전에 프로그램을 직접 끌 필요가 없습니다.
- **테마 선택**: Apple 라이트(기본)·Apple 다크·클래식. 브라우저별로 기억됩니다.
- **검색 정확도**: 기업명이 "신규 확인 사항 없음" 줄에만 나오는 리포트는 검색·기업 필터·지도에서 제외합니다(해제 가능).
- **일일 자동 게시**: ChatGPT가 `data/reports/`에 리포트를 push하면 GitHub Actions가 catalog·DB를 재생성해 커밋합니다. 사용자 PC는 08:00 갱신으로 받습니다. 작성 규칙은 [리포트 작성·게시 규칙](REPORT_FORMAT.md)에 있습니다.
- `scripts/import-history.py`에 `--from-reports`(폴더 스캔)·`--if-changed` 모드를 추가했습니다. 기업 목록은 `data/companies.json`으로 분리했습니다.
- 비개발자용 [시작 안내](USER_GUIDE.md)를 추가했습니다. 설치·SmartScreen 경고 대처·화면별 사용법·자주 하는 질문을 그림과 함께 담았습니다.

실행 파일 자체 자동 업데이트와 코드 서명은 아직 제공하지 않습니다. 업데이트는 새 Setup을 다시 실행하면 됩니다.

# AV Report Hub v0.1.3

- 환경 검사 → 설치 → DB 준비 → 바로가기 생성 → 앱 실행을 자동으로 진행합니다.
- 사용자 공개 승인에 따라 2026-09-20~2026-10-14 리포트 19건과 MD·PPTX 38개를 포함합니다.
- SQLite 원본 DB와 같은 자료의 조회용 JSON을 제공합니다.
- 검색·기간 필터·타임라인·근거가 있는 관계 그래프를 제공합니다.
- 프로젝트 목적·구조·동작·데이터·운영·한계를 다룬 상세 설명서를 추가했습니다.
- Git·Python·Node 등 개발 환경을 일반 사용자 PC에 설치하지 않습니다.
- 동기화 안정화: ETag 조건부 요청으로 GitHub API 사용량 절감, PC별 0~10분 지터, 대용량 다운로드 타임아웃 분리, 미참조 캐시 자동 정리, `app.log`에 실패 원인 기록.
- 화면: 본문 표·목록·인용 렌더링, 상태 폴링 경량화(`/api/status`).
- 화면 개편: 모던 테마, 검색어 강조, 기업·분류 칩 필터, 인터랙티브 관계 그래프, 리포트·기업·분류 전체 지도 탭(드래그·확대·자동 맞춤), 상세 본문을 상단에 바로 표시.
