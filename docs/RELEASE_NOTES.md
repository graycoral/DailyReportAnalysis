# v0.1.0

- Windows x64용 `AVReportHub-Setup.exe`, `AVReportHub.exe`.
- 사용자의 Git·Python·Node.js·Go 설치가 필요 없는 독립 실행 패키지.
- 환경 검사, 사용자 폴더 설치, 바로가기, GitHub 공개/비공개 읽기 설정.
- 검색·타임라인·관계 그래프 및 원문·첨부 열람.
- 실행 시·지정 시각 갱신, 연결 실패 시 마지막 정상 자료 유지.
- 기존 샘플 리포트 1건 포함. SQLite DB 자동 준비 기능 추가. 전체 과거 DB의 공개 배포는 승인 대기.
- Windows 테스트와 설치/실행 검사를 통과한 파일을 게시합니다.

현재 버전은 코드 서명이 없으며, 일일 자동 게시·Outlook 연결·Windows 자동 시작 기능은 후속 단계입니다.

Setup EXE 하나를 실행하면 설치·DB 준비·바로가기 생성·리포트 실행까지 자동 진행합니다.
