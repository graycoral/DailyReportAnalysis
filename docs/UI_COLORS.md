# 화면 색상

`ui-ux-pro-max`의 문서·B2B 도구 팔레트 원칙에 따라 읽기 영역은 차분하게 유지하고, 주요 동작과 선택 상태에 현대 블루를 사용한다. 색상은 `internal/hub/web/style.css`의 의미별 변수로 관리하며 앱·도움말·노트에 함께 적용한다.

공식 색상 출처: [현대자동차 CI 색상 규정](https://www.hyundai.com/kr/ko/info/ci/ci-color). 아래의 UI 보조색은 해당 공식 색상과 구분한다.

| 용도 | 라이트·클래식 | 다크 | 선택 이유 |
| --- | --- | --- | --- |
| 주요 버튼·선택 테두리 | `#002C5F` 현대 블루 | `#AACAE6` 스카이 블루 | 밝고 어두운 바탕 각각에서 동작을 명확하게 표시 |
| 주요 버튼 글자 | `#FFFFFF` | `#002C5F` | 대비 약 13.77:1 / 8.06:1 |
| 버튼 hover | `#001F45` | `#C1DBEF` | UI 보조색, 상태 변화를 명확하게 표시 |
| 페이지 바탕 | `#F6F3F2` 라이트 샌드 | `#0F1B2B` | 문서 중심의 편안한 바탕; 다크는 UI 보조색 |
| 리포트·카드 | `#FFFFFF` | `#16283D` | 긴 본문을 읽는 영역 구분 |
| 본문 글자 | `#243746` | `#F3F6FA` | UI 보조색, 검정보다 부드러운 대비 |
| 보조 글자 | `#596875` | `#A9BBCC` | 작은 안내 문구의 가독성 확보 |
| 선택 배경 | `#E9F2F8` | `#203C58` | UI 보조색, 테두리·굵기와 함께 선택 표시 |
| 구분선 | `#E4DCD3` 샌드 | `#33495E` | 장식용 영역 구분 |
| 입력·버튼 테두리 | `#788A99` | `#7C8FA3` | UI 보조색, 조작 가능한 영역은 구분선보다 진하게 |

클래식 헤더는 현대 블루 바탕에 흰 글자와 스카이 블루 보조 글자를 쓴다. 다크 모드에서는 스위치 손잡이와 버튼 글자에 현대 블루를 사용한다. 헤더의 키보드 포커스 테두리는 헤더 글자색을 사용해 클래식에서도 보이도록 한다.

Active Blue `#00AAD2`와 흰 글자의 대비는 약 2.73:1이므로 작은 글자를 담는 버튼에는 사용하지 않는다. 일반 텍스트는 [WCAG 최소 명암 대비](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html)의 4.5:1을 기준으로 확인한다. 지도·그래프의 자료 종류별 색상과 성공·오류 상태 색상은 각 의미를 유지한다.

화면의 이름은 블루 라이트·블루 다크·블루 클래식이다. 기존 브라우저 설정과 링크를 보존하기 위해 저장 키 `apple`, `apple-dark`, `classic`은 유지한다.
