# 메인 화면 Hallmark 점검

2026-10-19 · 사용자가 승인한 네 항목을 수정했다. 기존 현대 블루 계열과 문서 중심 화면 구조는 유지한다.

| 심각도 | 발견한 패턴과 위치 | 수정 내용 | 이유 |
| --- | --- | --- | --- |
| Major | 모바일 보조 도구 과밀: `selection.js`, `selection.css`, `style.css` | 미선택 상태에서 개수·삭제·해제를 접고 선택·휴지통만 표시. 선택 안내는 다중 선택 모드에서 표시. 모바일 헤더·검색 도구 간격 압축 | 사용할 수 없는 도구와 긴 설명이 첫 리포트를 아래로 밀고 있었다. |
| Major | 서로 다른 아이콘 표현: `index.html`, `app.js` | 검색·업데이트·가져오기·지우기·접기·상태·모달 닫기를 기존 1.7px SVG 스타일로 통일 | 문자 글꼴마다 기호의 굵기와 기준선이 달라졌다. 접근 가능한 버튼 이름과 상태 메시지는 유지한다. |
| Minor | 메뉴 하나만 두 줄: `index.html`, `style.css` | 데일리리포트 줄바꿈 제거, 탐색 영역을 데스크톱 88px·작은 화면 80px로 조정 | 메뉴 이름을 자르지 않고 동일한 한 줄 리듬으로 읽을 수 있다. |
| Minor | 불필요한 유리 효과: `style.css` | 라이트·다크 헤더를 불투명 표면과 구분선으로 변경, backdrop blur 제거 | 화면 구획이 이미 분명해 흐림 효과가 정보 위계에 기여하지 않았다. 클래식의 진한 블루 헤더는 유지한다. |

선택 해제 버튼이 접힐 때 키보드 초점을 보이는 다중 선택 버튼으로 돌린다. 자료 선택·삭제·복원 정책은 그대로다.

검증: `go test ./internal/...`, Edge의 `check-hallmark-ui.cjs`, `check-selection-ui.cjs`, `check-audit-ui.cjs`, `check-help-ui.cjs`. Hallmark 검사는 320·375·414·768·1280px에서 가로 넘침과 메뉴 잘림을 확인하고, 첫 리포트가 화면 위쪽 500px 이내에 나타나는지 검증한다. 선택 도구의 조건부 표시와 키보드 초점 복원, 세 테마의 대비도 확인한다.

수정 전 지적: Critical 0 · Major 2 · Minor 2. 승인된 네 항목 모두 반영.
