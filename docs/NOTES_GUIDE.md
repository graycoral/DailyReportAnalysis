# 노트 사용 안내

왼쪽 **노트 → 새 노트**에서 제목과 본문을 작성합니다. 입력을 멈추면 약 0.9초 뒤 저장되며, 위쪽에 `저장 완료`가 표시됩니다. `지금 저장` 또는 편집기에서 `Ctrl+S`로 즉시 저장할 수도 있습니다. 노트를 바꾸거나 앱의 종료 버튼을 누르면 남은 변경을 먼저 저장합니다. 저장 실패 시 내용이 유지되고 화면 전환을 보류합니다.

## 작성과 보기

- **원문 편집**: Markdown 기호를 그대로 편집합니다.
- **분할 미리보기**: 원문과 결과를 함께 봅니다. 좁은 창에서는 위아래로 배치합니다.
- **읽기**: 서식이 적용된 본문만 봅니다.
- **Live Preview**: 현재 커서가 있는 문단·목록은 원문으로 편집하고, 다른 문단·표·이미지는 같은 편집 영역에서 서식으로 표시합니다. 문단을 클릭하면 해당 원문을 편집합니다. Obsidian 플러그인이나 모든 확장 문법을 지원하는 것은 아닙니다.

도구 모음에서 제목, 굵게, 기울임, 목록, 체크박스, 표, 링크, 노트 연결, 코드 블록을 넣을 수 있습니다. `Ctrl+Z`로 실행을 취소합니다. 한글 조합 중에는 자동 저장을 보류하고 조합이 끝난 뒤 저장합니다. 미리보기의 체크박스는 읽기 전용이며 원문에서 `[ ]`와 `[x]`로 수정합니다.

## 정리하고 연결하기

- 제목을 바꾸면 파일명도 바뀝니다. 폴더 입력란에 `기업 분석/기업 A`처럼 경로를 입력하면 이동합니다. 왼쪽 `＋ 폴더`로 빈 폴더를 만들 수도 있습니다.
- 태그 입력란에는 쉼표로 구분한 태그를 넣습니다. 본문에 쓴 `#태그`도 태그 필터와 자동완성에 사용됩니다.
- `[[`를 입력하면 노트 경로를 자동완성합니다. `[[기업 분석/기업 A]]`, `[[기업 A|표시 이름]]`으로 연결할 수 있습니다. 같은 제목이 여러 폴더에 있으면 경로를 사용하세요. 연결한 노트에는 역참조 목록이 표시됩니다.
- 노트 이름이나 폴더를 앱에서 변경하면 연결된 위키 링크와 일반 Markdown 링크, 이동한 문서의 상대 이미지 경로를 갱신합니다. 코드 블록과 인라인 코드, 사용자가 작성한 YAML 메타데이터는 그대로 유지합니다.
- 리포트 상세의 **관련 노트 작성**으로 출처를 연결한 노트를 만듭니다. 노트 아래에서 기존 리포트를 추가로 연결하거나 해제할 수 있습니다. 연결된 리포트를 클릭하면 원래 화면으로 돌아갑니다. 현재 목록에 없는 리포트의 연결 ID도 보존합니다.

## 관계 그래프와 전체 지도

**관계**와 **지도** 위쪽의 **내 노트**를 켜면 현재 저장 폴더의 노트가 표시됩니다. 기본값은 켜짐이며 다른 자료 스위치를 모두 꺼도 노트만 볼 수 있습니다.

- `[[노트 이름]]`과 `[표시 이름](상대경로.md)`은 실제로 존재하는 노트끼리 연결합니다. 별칭·제목 앵커·Markdown 참조 링크도 지원하며 같은 대상은 한 번 연결합니다. 코드 예제·이미지·외부 URL·YAML 속성과 이름만 같은 기업·태그는 연결로 만들지 않습니다.
- 노트 아래에서 직접 선택한 리포트도 연결합니다. 선을 누르면 출발 노트의 경로와 링크 또는 리포트 연결 근거를 확인합니다. 노트를 누르면 미리보기와 **노트 열기 · 편집**이 나옵니다.
- 연결 없는 노트도 전체 지도의 보라색 점과 관계 화면의 **연결 없는 노트**에 표시합니다. 지도는 처음에 전체 자료를 보여주고, 점을 선택하면 주변 연결을 확대합니다. **전체 보기**로 돌아갈 수 있습니다.
- 검색어는 노트 제목·경로·본문·태그에도 적용됩니다. 기업·분류·기간 조건은 리포트에만 적용됩니다. 연결선은 양쪽 자료가 모두 표시될 때만 나타납니다.
- 화면 진입 시와 관계·지도 화면을 보는 동안 약 4초마다 파일을 다시 확인합니다. 외부 수정·삭제·복원과 저장 폴더 변경도 반영됩니다. 파일을 읽지 못하면 오류와 다시 시도를 표시합니다.

노트 링크는 개인 자료의 참조 관계입니다. 기업·사건의 확인된 사실 관계에 추가되거나 GitHub로 전송되지 않습니다.

## 이미지와 기존 Markdown

PNG, JPEG, GIF, WebP 이미지를 붙여넣거나 끌어놓거나 `이미지` 버튼으로 추가합니다. 파일당 10MB 이하입니다. 이미지는 노트 폴더의 `첨부`에 저장하고 Markdown에는 상대 경로를 넣습니다. 폴더 전체를 복사하면 이미지도 함께 유지됩니다. 외부 이미지 URL은 자동 다운로드하지 않습니다.

`MD 가져오기` 또는 노트 화면에 끌어놓기로 UTF-8 `.md`를 가져옵니다. 노트 본문은 2MB 미만을 지원합니다. 같은 이름은 숫자를 붙여 사본으로 가져오며 원래 파일을 덮어쓰지 않습니다. Markdown 파일만 가져오면 그 파일의 외부 첨부는 자동 복사되지 않습니다. 기존 노트와 이미지 폴더 전체를 사용할 때는 **저장 폴더**에서 해당 폴더를 여세요.

## 파일 위치와 외부 편집

기본 폴더는 `%LOCALAPPDATA%\AVReportHub\notes`입니다. 노트는 평문 `.md`이며 기존 `내 자료`의 DPAPI 암호화와 저장 방식이 다릅니다. 노트 저장소는 GitHub 리포트 동기화·공개 catalog·AI 검색에 자동 편입되지 않습니다.

**저장 폴더**에서 Windows 폴더 선택 창이나 절대 경로로 다른 폴더를 열고, 탐색기에서 확인할 수 있습니다. 위치 변경은 다른 노트 저장소를 여는 동작입니다. 기존 파일은 원래 위치에 남습니다. Git 저장소 안의 폴더는 선택할 수 없습니다.

일반 Markdown 본문과 사용자가 작성한 front matter는 유지합니다. 앱은 다음 YAML 호환 필드를 관리합니다.

```yaml
avhub_id: "n-고유ID"
avhub_tags: ["분석", "회의"]
avhub_reports: ["리포트ID"]
```

이 필드로 이름이 바뀌어도 노트 식별과 리포트 연결을 유지합니다. Obsidian에서도 같은 폴더를 열 수 있습니다. 앱이 사용하는 태그 필드는 `avhub_tags`이므로 Obsidian의 `tags` 속성과 자동 동기화되지는 않습니다. 본문의 `#태그`는 일반 텍스트로 유지됩니다.

노트 탭이 열려 있을 때 약 5초마다 외부 변경을 확인합니다. 편집 중이 아니면 최신 파일을 반영하고, 작성 중이면 **변경 내용 비교**를 표시합니다. 여기에서 내 내용을 사본으로 저장하거나 파일의 최신 내용을 불러옵니다. 외부 편집기에서 이름을 바꾸면 파일 변경은 반영되지만 외부에서 변경한 링크까지 앱이 추론해서 갱신하지는 않습니다.

## 삭제와 복구

- 삭제한 노트는 `.avhub/trash`로 옮기고 휴지통에서 복원합니다. 같은 경로가 있으면 복원 사본 이름을 사용합니다. 첨부 이미지는 다른 노트에서도 사용할 수 있어 함께 삭제하지 않습니다.
- 수정 전 파일의 최근 50개 저장본을 `.avhub/history`에 보관합니다. **이전 저장본**에서 선택하면 현재 노트에 복구하며 복구 직전 내용도 기록합니다.
- `.avhub` 폴더도 함께 백업하면 휴지통과 저장 이력을 보존할 수 있습니다. 앱이나 PC가 갑자기 종료되면 마지막 `저장 완료` 이후 입력은 남지 않을 수 있습니다.

## 개발·검증

편집기 소스는 `frontend/`, 서버는 `internal/hub/notes*.go`, 스타일은 `internal/hub/web/notes.css`입니다. CodeMirror와 Markdown-it은 잠금 파일로 버전을 고정해 `internal/hub/web/notes.js`에 묶고, 라이선스를 `notes-licenses.txt`에 포함합니다. 배포 실행에는 Node.js가 필요하지 않습니다.

```powershell
npm ci
npm run build:notes
go test ./internal/...
go build -o build/notes-viewer.exe ./cmd/viewer
node scripts/check-notes-ui.cjs
node scripts/check-note-network.cjs
node scripts/check-note-network-ui.cjs
```

브라우저 검증은 독립된 임시 데이터 폴더와 headless Edge를 사용합니다. 실제 사용자 자료를 변경하지 않습니다. 스크린샷은 `build/notes-ui`에 저장합니다.
